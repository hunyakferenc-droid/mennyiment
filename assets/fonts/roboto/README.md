# Local default Roboto

Unmodified Roboto font assets from the official Flutter 3.47.7 SDK's
bin/cache/artifacts/material_fonts bundle. Apache License 2.0 (LICENSE.txt).
Flutter upstream: https://github.com/flutter/flutter/tree/3.47.7

Registered with the original family name Roboto. CanvasKit otherwise downloads
its mandatory default font from fonts.gstatic.com even when resource CDN loading
is disabled. Bundling the default keeps HU/EN startup and reload local.
