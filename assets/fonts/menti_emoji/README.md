# Local emoji fallback

Unmodified Noto Color Emoji, upstream v2.051, licensed under SIL OFL 1.1 (OFL.txt).
Source: https://github.com/googlefonts/noto-emoji/tree/v2.051/fonts
Font: https://raw.githubusercontent.com/googlefonts/noto-emoji/v2.051/fonts/NotoColorEmoji.ttf
SHA-256: 72a635cb3d2f3524c51620cdde406b217204e8a6a06c6a096ff8ed4b5fd6e27b

Bundled as MentiEmoji so HU/EN app emoji and emoji in saved names do not need
Google's runtime fallback font service. This adds no telemetry or permissions.
The original Menti character images and identity options are not modified.
