# 2.2.5 – teljes testreszabási audit

Kiindulás: PR #34, `0246aaedc120348f9e060c50d68e18a98bb6f225`. Az eredeti referenciák változatlanok.

## Reprodukció és lefedettség

`MENTI_AUDIT=1 MENTI_STAGE=before flutter test test/menti_audit_225_test.dart` a tényleges Flutter-renderert használja. Kilenc család/kor panel, panelenként 103 kompatibilis opció (összesen 927), külön 180 ruhanézet, 18 összetett karakter. Az idegen családok 12 hajazonosítója panelenként kizárt; az összes 115 ID legalább egy panelen szerepel. A konfigurációk a manifestben vannak.

Az alábbi súlyosság az adott kategóriában feltárt hibatípus prioritása, nem állítás arról, hogy minden egyes konfiguráció hibás. A `none` elemek eltávolítási állapotok. P0 adatvesztést vagy alapkarakter-szétesést az audit kiinduló képein nem igazoltunk. A művészi elfogadás nem automatizált státusz.
