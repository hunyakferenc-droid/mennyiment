Ellenőrzött alkalmazásforrás: `2a794bfa87bd9f0ad8713f6a0ed350083e43c9e7`. [Draft PR #36](https://github.com/hunyakferenc-droid/mennyiment/pull/36), a #35 fejlesztési ágára. [Képes jelentés és nyitott határok](2.2.6-naturalization-report-hu.md).

[Letölthető web ZIP](https://github.com/hunyakferenc-droid/mennyiment/actions/runs/41697520346/artifacts/13262875945). GitHub-hozzáférés szükséges; az artifact 2026. november 17-ig őrzött.

Telepített Flutter 3.47.7 / Dart 3.13.5 mellett a projekt helyi másolatában:

```sh
git fetch origin feature/mennyiment-2-2-6-naturalization
git switch --detach 2a794bfa87bd9f0ad8713f6a0ed350083e43c9e7
flutter pub get
flutter gen-l10n
flutter run -d chrome --web-port 7357
```

Ha a Flutter nem talál Chrome eszközt:

```sh
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 7357
```

Chrome-ban: `http://127.0.0.1:7357`. A Studio címe 2.2.6, a build verziója 2.2.6+28.

Kész web ZIP-ből is indítható: bontsd ki, a kibontott könyvtárban indíts `python -m http.server 7357` kiszolgálót, és nyisd meg ugyanezt a címet. HTTP szükséges a `file://` megnyitás helyett.

A meglévő böngészőadatok ugyanazon Chrome-profil, host és port használatakor érhetők el. Eltérő port külön helyi tárhely; a korábbi mentés ettől nem törlődik. Átvitelhez a meglévő backup/restore használható. Böngészőadatot és régi Android-alkalmazást ne törölj a próbához; új telefonos telepítés nem szükséges.

Tulajdonosi vizsgálat: mindhárom család mindhárom kora, normál méretű előnézet és nagyító; szemüvegszár a haj mellett, napszemüveg mérete, sál az áll alatt, üzleti ruha csokornyakkendővel, mandzsetta/kéz/tárgy kapcsolata, több kiegészítő együtt. Próbáld a mentést, visszavonást és újratöltést is. Az új anyagok művészeti elfogadása még nyitott.
